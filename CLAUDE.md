# pf-privilege-obo-LAB

Demo-tier standalone: simulated PingFederate → Privilege OBO chain (flow sim + measured-issues panel).

- Run: `npm ci && npm start` (port 7812) or `docker compose up --build -d`
- Test: `npm test` (node --test + vitest + repo checks), `npm run doctor`
- Rules that bite: Mock by default; Real runs live OBO against YOUR tenant only when this lab's `.env` is complete (else 409), loopback-only publish, no raw tokens in MOCK run records
  (claims + sha256/8 only; Real frames show real demo tokens in full), vendored `web/standalone-ui.css` must match the family canonical
  (`npm run test:repo` checks it), scenario data lives in `server/src/scenarios.js`.
- What Privilege did (Rule 25 panel): `POST /api/run` attaches `trace` (built by `server/src/oboTrace.js` from the hops `runChain` computed) and `FlowSim.jsx` renders `<GatewayTrace>` under the run result. The files are vendored byte-for-byte from AI-DEMO-Standalone `shared/gateway-trace` and pinned by `web/src/gateway-trace/gateway-trace.sha256` (`test/gateway-trace.test.js`): `web/src/gateway-trace/*` and `server/src/gatewayTrace.js` (NOT `trace.js`). Never hand-edit them; re-vendor with cp, then re-pin. Honesty rule: the MOCK decisions are `checked` only because `runChain` computed them (a check an earlier refusal never reached is `skipped`); a real gateway reports no per-check detail, so Real (`oboReal.js`) labels its checks `inferred` and reports only accepted or refused. No token (not even the garbage control) goes in a trace, only its length.
- Real OBO (`server/src/oboReal.js`, `web/src/RealObo.jsx`): settings `PFO_USER_*` and `PFO_OBO_*` from the lab `.env` (or the environment; `PFO_ENV_FILE` overrides the path, tests point it at /dev/null). Two shapes (`agent`, `gateway`) run as numbered frames; `POST /api/real/obo/run {shape, refusal}`. The netguard allows only the configured hosts once Real is on (lookups included). Tokens ARE shown in full in a frame (demo; owner 2026-11-22: tokens may be shown, the family shows them raw); client secrets and the password never reach a frame (tests assert it). Tests use an in-process stub of PingFederate and the doors (`test/obo-real.test.js`). The video build is `video/` (SCRIPT.md first; `video/assets` and `video/out` are gitignored). Settings are never committed: the repo is public and forbids tenant identifiers.
